# Historial semanal

Al cerrar una semana, copiar `../semana_actual.md` con el primer numero libre:

```text
semana_01.md
semana_02.md
semana_03.md
```

La copia debe conservar pesos, repeticiones, RIR, descansos, estado laboral, preferencias, sustituciones y respuesta lumbar. Nunca se sobrescribe una semana anterior. Despues, limpiar `semana_actual.md` y actualizar su numero.

Para analizar una etapa, comparar sesiones del mismo patron y revisar primero tecnica, RIR, fatiga y respuesta del dia siguiente; el peso por si solo no decide si hubo progreso.
